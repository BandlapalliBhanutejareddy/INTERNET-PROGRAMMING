## 1. Repository Overview

This repository has been streamlined to a clean, minimal project structure focusing on core web development fundamentals:

- **[LAB/index.html](LAB/index.html)**: A complete, responsive, standalone HTML5 & CSS3 website featuring the lab introduction, experiment cards (Experiments 1 through 5), course learning outcomes, and a contact form.
- **[LAB/README.md](LAB/README.md)**: Comprehensive laboratory documentation detailing aims, technologies, experiment descriptions, running steps, editing guidelines, and browser verification instructions.
- **[.gitignore](.gitignore)**: Clean configuration excluding operating-system metadata, editor caches, and temporary files.

## 3. How to View the Website

Open [`LAB/index.html`](LAB/index.html) directly in any modern web browser:
1. Double-click `LAB/index.html` in your file explorer, or
2. Open with terminal:
   ```powershell
   start LAB/index.html
   ```

No web server, PHP, Node.js, database, or external library is required.
