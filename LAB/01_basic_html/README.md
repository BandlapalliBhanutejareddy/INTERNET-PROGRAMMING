# Experiment 01: Basic HTML5 Document Structure & Elements

## Title
Design a structured web page using HTML5 semantic elements, text formatting, hyperlinks, lists, and tables.

## Aim
To understand and implement the foundational structure of an HTML5 document including semantic tags (`<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`), headings, paragraphs, blockquotes, ordered/unordered lists, and data tables.

## Algorithm
1. Start the document with the `<!DOCTYPE html>` declaration to specify the HTML5 standard.
2. Create the root `<html>` element and define the `<head>` section containing meta character set, viewport settings, and the page title.
3. Define the `<body>` element to hold visible content.
4. Use semantic structure tags (`<header>`, `<nav>`, `<section>`, `<footer>`) to partition content logically.
5. Create a navigation bar with anchor links pointing to section IDs.
6. Present information using headings (`<h1>`, `<h2>`), paragraphs (`<p>`), and a blockquote.
7. Implement an unordered list (`<ul>`) for department categories and an ordered list (`<ol>`) for rules.
8. Construct an HTML `<table>` with `<thead>`, `<tbody>`, `<tr>`, `<th>`, and `<td>` to represent circulation timings.
9. Save the file with the `.html` extension and render it in any standard web browser.

## Source Code
See `index.html` in this directory.

## Sample Input
User navigates to `index.html` in a web browser.

## Expected Output
A well-structured, formatted library information page displaying:
- Header with university and course title
- Hyperlink navigation bar
- Section with descriptive paragraph and blockquote
- Bulleted list of departments
- Formatted table containing library opening hours and status badges
- Numbered list of borrowing guidelines
- Footer with copyright notice

1. Open Google Chrome, Microsoft Edge, or Mozilla Firefox.
2. Press `Ctrl + O` and browse to `LAB/01_basic_html/index.html`.
3. Verify that all semantic elements, lists, and tables render correctly.
