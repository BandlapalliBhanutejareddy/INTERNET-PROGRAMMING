Welcome to the Internet Programming Lab portal. This course provides hands-on practical experience in modern web fundamentals, enabling undergraduate computer science engineering students to design semantic, accessible, and responsive websites using HTML5 and CSS3.

Laboratory Experiments

Explore fundamental hands-on exercises developed throughout the Internet Programming Lab course.

Experiment 01

Basic HTML Structure

Learn core HTML5 semantic elements, page metadata, document heading hierarchy (h1 to h6), paragraphs, blockquotes, and text formatting.

  • DOCTYPE html declaration
  • Header, nav, main, and footer semantics
  • Headings, paragraphs & formatting
Experiment 02

HTML Forms

Design interactive user input forms using text fields, emails, passwords, radio buttons, checkboxes, dropdown select menus, and native validation.

  • Input types (text, email, password, date)
  • Labels, fieldsets, and legends
  • Form validation attributes (required, pattern)
Experiment 03

CSS Styling

Master modern styling with CSS selectors, the CSS box model (margin, border, padding), typography, color palettes, and responsive flexbox layouts.

  • CSS selectors and custom variables
  • Box model and spacing properties
  • Flexbox layout and hover transitions
Experiment 04

Tables and Lists

Present structured tabular data cleanly using HTML tables with headers, body rows, zebra striping, along with ordered and unordered list elements.

  • Table elements (table, thead, tbody, th, td)
  • Ordered (<ol>) and unordered (<ul>) lists
  • Border collapse and table alignment styling
Experiment 05

Links and Images

Implement hyperlinking architectures including internal page bookmarks, external references, target attributes, and responsive accessible images.

  • Anchor tags (<a>) with href targets
  • Internal page anchor jumps (#id)
  • Images (<img>) with alt text and sizing

About the Course

Department of Computer Science & Engineering • Saveetha School of Engineering (SIMATS)

The Internet Programming Lab (CSA4315) is designed to equip engineering students with foundational knowledge in client-side web development. Students learn how the World Wide Web operates, how browsers parse HTML documents, and how CSS rules style visual presentation.

Through structured practical sessions, learners progress from basic static markup to creating accessible, multi-page layouts that render consistently across desktop monitors, laptops, tablets, and smartphones.

Key Learning Outcomes

  • Author valid, semantic HTML5 documents according to W3C standards.
  • Apply CSS3 styling, color theory, and responsive layout techniques.
  • Construct accessible web forms with client-side constraints.
  • Structure tabular datasets and hyperlinked navigation flows.
  • Prepare for full-stack engineering and modern front-end technologies.
